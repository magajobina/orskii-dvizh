# Инструкции для работы с проектом

## Генерация и правка иллюстраций

Перед любой генерацией или изменением игровой фотографии прочитай [памятку по стилю](docs/IMAGE_STYLE.md). В ней записаны согласованные с пользователем требования, источники лиц и удачный пример фильтра. Ориентируйся на эти изображения, а не только на словесное описание.

- Пользователь предпочитает мягкий, слегка размазанный исходный фотофильтр; чрезмерная резкость и детализированная цифровая живопись не подходят.
- При правке сохраняй конкретных людей, их одежду, композицию и уже согласованные детали. Если лицо уехало, не закрепляй чужую внешность последующими итерациями: вернись к настоящим фотографиям человека.
- Не меняй сюжет и расстановку сцен при запросе только на картинки. Сохраняй результаты в проект и добавляй новые изображения в галерею через `src/content/assets.json`.
- По умолчанию создавай отдельную версию. Если пользователь просит заменить существующую картинку, сохрани прежнюю в `output/imagegen/backups/`, затем замени файл по прежнему пути.
- Следуй последнему запросу пользователя; эта памятка задаёт значения по умолчанию, а не отменяет новые указания.
