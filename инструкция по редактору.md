# Инструкция по редактору

## Запуск

В папке проекта выполните `npm run dev`, откройте адрес, который напечатает Vite, и добавьте `/?editor`. Например: `http://localhost:5173/?editor`.

Редактор работает локально, без БД и внешних сервисов. Кнопка «Сохранить в проект» записывает JSON через локальный сервер Vite. В сборку `npm run build` редактор и API записи не входят: на GitHub Pages параметр `?editor` открывает обычную игру.

## Из чего состоит сюжет

Стрелка означает, какой блок выполнится следующим. Обычный блок имеет один выход справа, а у «Выбора» свой выход напротив каждого ответа. Вход находится слева. Чтобы соединить блоки, потяните мышью от кружка выхода к кружку входа. Можно также указать ID цели в поле «Следующий блок» или «Переход» справа. Для соединения разных глав удобно скопировать ID нужной цели и вставить в это поле.

Лишние блоки «Переход», оставшиеся от Ren’Py, удалены: стрелки ведут сразу в нужную реплику, картинку или выбор. Для связи между главами отдельный блок не требуется. Импорт старого бэкапа может вернуть прежние блоки «Переход»; такой блок автоматически переходит к цели, ничего не показывая игроку.

## Верхняя панель: создание и работа с блоками

| Кнопка | Что делает |
| --- | --- |
| **+ Реплика** | Создаёт текст, который игрок увидит в нижней плашке. После клика игрока выполняется следующий блок. Текст редактируется справа. |
| **+ Картинка** | Создаёт команду смены иллюстрации. Выберите файл в галерее и подключите следующий блок. Смена картинки выполняется автоматически, отдельного клика не требует. Картинка остаётся до следующей команды смены изображения. |
| **+ Выбор** | Создаёт меню ответов. У каждого ответа собственные текст и цель. Пока меню открыто, игра ждёт выбора игрока. |
| **+ Конец** | Создаёт конечную точку ветки: игра показывает «Конец», дальше по клику сюжет не продвигается. Для финальной реплики сначала создайте «Реплику» и соедините её с «Концом». Блок не завершает редактирование и не закрывает редактор. |
| **↶ Отменить / ↷ Повторить** | Отменяет изменение документа или возвращает отменённое. Поддерживает изменение текста, перемещение, создание, удаление, соединение блоков и автоматическую раскладку. Перемещение камеры не является редактированием сюжета. |
| **Копировать** | Копирует выделенные блоки. Связи между ними сохраняются при вставке. |
| **Вырезать** | Копирует и удаляет выделенные блоки. Входящие связи на удалённые блоки разрываются. |
| **Вставить** | Создаёт копии в текущей главе с новыми ID. Внутренние связи переводятся на копии; внешние цели сохраняются, если такие блоки есть в проекте. |
| **Удалить** | Удаляет выделенные блоки или стрелки. При удалении блока его соседние блоки автоматически не соединяются — проверьте оставшиеся связи. |
| **Разложить** | Автоматически расставляет блоки текущей главы слева направо с учётом связей. Продолжения ответов располагаются сверху вниз в порядке вариантов; возвратные стрелки к меню не определяют направление раскладки. При общих целях и противоречащих друг другу ветках некоторые пересечения могут быть необходимы. Меняет только расположение карточек, не текст и не последовательность сюжета. Результат можно отменить. |
| **Вся схема** | Подбирает масштаб и положение камеры, чтобы поместить на экране схему текущей главы. Карточки не перемещает. |
| **Старт** | Переключает схему на главу начала игры, выделяет начальный блок и приближает его. Не запускает прохождение. Для проверки игры используйте «Игра» или «Играть с этого блока». |

Кнопки создания можно нажать или перетащить на нужное место холста. Новый блок пока не подключён к истории: соедините его стрелками. У новой реплики или картинки может быть автоматически выбрана цель «Конец» — замените её, если сюжет должен продолжаться.

## Холст и левая панель

| Действие | Управление |
| --- | --- |
| Выбрать блок и открыть его свойства | Клик по карточке или пункту проводника слева. |
| Переместить блок | Потянуть карточку левой кнопкой мыши. |
| Переместить холст | Пробел + перетаскивание; либо перетаскивание средней или правой кнопкой мыши. Обычная прокрутка также перемещает холст. |
| Приблизить / отдалить | Ctrl + колесо; кнопки «+» / «−» на холсте; жест масштабирования на тачпаде. На Mac — Command вместо Ctrl. |
| Выделить несколько блоков | Shift + клик; либо рамкой на пустом месте холста. Выделенную группу можно перемещать вместе. |
| Поменять соединение | Перетянуть конец существующей стрелки к другому блоку. |
| Изменить ширину проводника | Потянуть его правую границу. Ширина запоминается в этом браузере. Границу можно выделить клавишей Tab и менять ширину стрелками влево / вправо. |

Масштаб и положение камеры автоматически запоминаются отдельно для каждой главы в этом браузере, вместе с последней открытой главой. После переключения и перезагрузки страницы возвращается прежний вид; нажимать «Сохранить в проект» для камеры не нужно. Камера не откатывается через Ctrl+Z. Поиск блока и кнопка «Старт» по-прежнему намеренно приближают нужный блок.

В проводнике выберите главу. На холсте показаны только её блоки; ссылки на другие главы отображаются дополнительными карточками целей. Клик по такой карточке открывает соответствующую главу. При небольшом окне проводник скрывается, а выбор главы остаётся в верхней панели.

Поиск «ID или текст блока» ищет по всему сюжету. Клик по результату открывает его главу и приближает блок; Enter открывает первый результат. Длинные реплики в списке сокращены многоточием: наведите мышь, чтобы увидеть полный текст в браузерной подсказке.

## Правая панель

**Блок** — свойства выбранной карточки. ID служит адресом для стрелок и отладки. Чтобы переименовать его, измените поле и нажмите «Применить»: ссылки обновятся автоматически. Поле «Глава» определяет, на какой схеме будет карточка и какая подпись главы появится в игре.

Для картинки кнопка «Открыть галерею» показывает имеющиеся иллюстрации, их названия и размеры. Поиск фильтрует список; клик выбирает изображение. Галерея выбирает из ассетов проекта, загрузки новых файлов в ней нет.

У «Выбора» можно добавлять и удалять ответы, менять их порядок кнопками ↑ / ↓, текст, ID и цель. «Реплика-подпись» — ID реплики-вопроса, который следует показывать под меню. Обычно цепочка такая: `Реплика с вопросом → Выбор → Ответная реплика`. Варианты появятся после отдельного клика по вопросу.

Для ложного выбора включите у ответа **«Скрыть после выбора»**, соедините его с отказной репликой, а ту — обратно с этим же меню. После возврата выбранный ответ исчезнет. Укажите реплику-подпись, чтобы меню снова показывало вопрос, а не последнюю отказную реплику. Оставляйте хотя бы один доступный ответ, который продолжает сюжет.

**Играть с этого блока** — открывает отдельную вкладку с текущим черновиком, начиная с выбранного блока. Записывать его в файлы для такой проверки не обязательно. При нескольких входящих ветках проверьте выбранную для старта картинку: редактор подбирает её по предшествующим сценам, но конкретный путь игрока может отличаться.

**Сюжет** — начало игры, обложка и список глав. Для главы доступны название, ID, первый блок и изображение. «Добавить главу» создаёт главу и её первую реплику. Удаление главы не удаляет её блоки: они окажутся в «Нераспределённых».

**Проверка** — ошибки ссылок, изображений, автоматических циклов и предупреждения о недостижимых или нераспределённых блоках. Клик по пункту открывает проблемный блок. Ошибки блокируют сохранение в проект; предупреждения — нет. Бэкап или экспорт доступны и для незавершённого черновика.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+Z | Отмена. |
| Ctrl+Y или Ctrl+Shift+Z | Повтор. |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать / вырезать / вставить выделенные блоки. |
| Ctrl+A | Выделить все блоки текущей главы. |
| Delete или Backspace | Удалить выделенные блоки или стрелки. |
| Ctrl+S | Сохранить в проект. |

На Mac используется Command. В текстовых полях копирование, выделение и отмена работают с текстом; Ctrl+S сохраняет проект. Аналогичные действия с блоками доступны кнопками панели.

## Сохранение, импорт и бэкапы

| Элемент | Что делает |
| --- | --- |
| **Игра** | Открывает обычную игру из сохранённых исходников в отдельной вкладке. |
| **Сохранить в проект** | Записывает сюжет в `src/content/story.json`, расположение блоков — в `src/content/editor-layout.json`. Камера сохраняется автоматически отдельно в браузере. Перед записью делает копию предыдущей версии. |
| **Экспорт JSON** | Скачивает только сюжет: реплики, сцены, ответы, связи и главы. |
| **Импорт** | Открывает JSON сюжета или полную резервную копию. Сначала сохраняет бэкап текущего состояния, затем открывает импорт в редакторе. В исходники он попадёт после «Сохранить в проект». |
| **Бэкапы** | Открывает список локальных резервных копий. |
| **Создать бэкап** | Сохраняет весь текущий сюжет и схему в `.editor-backups/`; можно указать название копии. Не заменяет исходники. |
| **Скачать полную копию** | Скачивает JSON с сюжетом и расположением блоков, пригодный для импорта. |
| **Восстановить** | Перед открытием копии создаёт бэкап текущего черновика. Восстановленная версия сначала открывается для просмотра; запись в исходники — отдельной кнопкой сохранения. Операцию можно отменить. |
| **Скачать** рядом с бэкапом | Скачивает выбранную сохранённую копию. |

Редактор автоматически хранит черновик в браузере. При перезагрузке кнопка «Восстановить черновик» возвращает его, а «Оставить файл проекта» отбрасывает браузерный черновик и оставляет данные из исходников. Если файлы менялись снаружи, выбирайте актуальную версию осознанно. При конфликте ревизий запись отклоняется: экспортируйте черновик перед перезагрузкой.

Локальные бэкапы исключены из Git. JSON хранит ссылки на картинки, а сами изображения находятся отдельно в `src/assets/illustrations/`. Для полной резервной копии с изображениями сохраняйте папку проекта или репозиторий. `docs/STORY.md` — прежний читаемый снимок сценария; рабочий источник игры — `src/content/story.json`.
