# Орский движ

Браузерная визуальная новелла о лётной практике студентов СПб ГУГА в Орске. React + TypeScript + Vite, статическая сборка для GitHub Pages. Сервер и конвертация сценария для работы игры не нужны.

## Запуск

```powershell
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173/`. Основное оформление — «Кино». Кнопки справа сверху переключают близкие вариации без сброса прохождения: «Кино», «Прохлада», «Закат» и «Плёнка». Прямая ссылка: `?theme=amber`. Для проверки первой развилки на балконе: `?theme=cinema&scene=balcony`.

## Управление

- Клик по экрану, Space или Enter — следующая реплика.
- После подписи меню нужен ещё один клик: только затем появляются варианты по центру столбиком.
- Пока открыты варианты, фоновые клики ничего не выбирают.
- Ложные развилки сохраняют исходное поведение: после отказной реплики открывается вложенное меню без отвергнутого варианта. Например, цепочка лимончелло сокращает меню с трёх ответов до двух и затем до одного.
- Маленькая кнопка «Назад» снизу или ArrowLeft возвращает предыдущее состояние, включая картинку и меню.
- «Главное меню» возвращает на старт. Выбор главы доступен на стартовом экране.

## Рабочие исходники

```text
src/
  content/story.json       сюжет, тексты, выборы и переходы — редактировать здесь
  content/assets.json      реестр изображений
  content/assets.ts        URL ресурсов для сборки
  assets/illustrations/    34 оригинальные иллюстрации
  assets/decorations/      очищенные схемы DA-40 и винта, без подписей
  engine/engine.ts         прохождение, выбор и история отката
  main.tsx                 экраны и управление
  styles.css               четыре оформления
tests/engine.test.mjs      проверки переходов и отката
public/licenses/           лицензии локальных шрифтов
docs/STORY.md              читаемая копия всего сценария
```

`src/content/story.json` — самостоятельный веб-формат. Он содержит все 112 текстовых команд, 26 сюжетных меню и 51 вариант ответа. Четыре прежних пункта быстрого перехода заменены обычным выбором главы. Пустые недостижимые команды убраны. Нет этапа генерации сцен или подготовки ресурсов перед запуском.

У одной сцены возвращения Ярика на машине нет своей картинки. В `assets.json` явно указан временный `fallback` на существующее изображение с предложением купить жигули; его можно заменить новым файлом. Остальные оригинальные иллюстрации сохранены без изменения содержимого. Текст и орфография сохранены.

## Проверка и сборка

```powershell
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`, пути относительные и подходят для размещения в подпапке GitHub Pages. `npm run preview` — стандартный локальный сервер готовой сборки Vite.
