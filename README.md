# Орский движ — подготовка веб-версии

Фановая визуальная новелла о лётной практике студентов СПб ГУГА в Орске. Здесь собраны материалы из готовой Windows-сборки «Орский движ» 1.0 на Ren’Py 7.4.2 и план переноса на GitHub Pages.

**Текущий этап: интерактивный прототип интерфейса.** Есть три оформления, главное меню, выбор четырёх глав и первая развилка каждой главы с одной ответной репликой. Полное прохождение пока не перенесено.

## Запуск веб-прототипа

```powershell
npm install
npm run dev
```

Открыть адрес, напечатанный Vite (обычно `http://localhost:5173/`). Кнопки внизу переключают оформление и на главном, и на игровом экране. Выбор запоминается в браузере; прямая ссылка с `?style=book`, `?style=night` или `?style=poster` открывает конкретный вариант.

```powershell
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт `dist/`. Пути относительные, подходят для GitHub Pages в подпапке репозитория. Публикация пока не выполнялась.

[Описание трёх вариантов и границ прототипа](docs/INTERFACE.md).

## Что сохранено

123 файла из каталога `game`, 45 458 404 байта (около 43,35 МиБ): оригинальные `.rpy`, их скомпилированные версии, настройки, интерфейс, перевод стандартных экранов, 34 сюжетных изображения и 78 изображений интерфейса. Музыка, звуки, видео и отдельные файлы шрифтов в `game` отсутствуют.

Сценарий содержит 20 блоков `label`, 27 меню, 55 вариантов выбора, 112 текстовых строк-команд (включая подписи меню), 33 команды смены сцены и 47 переходов `jump`. Подробности проверки — в отчёте.

## Структура текущего проекта

```text
orsk-web/
  source/
    renpy/game/              оригинальные файлы игры, без изменений
    build-info/traceback.txt старый отчёт о падении из сборки
  content/
    story.extracted.json    структурная выгрузка сценария с вложенными выборами
    assets.json             пути, размеры, SHA-256 и ссылки на строки сценария
    source-inventory.json   опись каждого файла исходного game
    extraction-report.json  результат проверок и недостающие ресурсы
  docs/
    STORY.md                весь сюжет в читаемом виде
    BRANCHES.md             граф переходов Mermaid
    ASSETS.md               каталог и галерея
    ARCHITECTURE.md         план React + TypeScript + Vite
    EXTRACTION.md           происхождение материалов и замечания к переносу
  tools/
    extract_sources.py      воспроизводимое извлечение, Python 3 без зависимостей
    prepare-preview.mjs     готовит игровые иллюстрации и первые выборы глав
  src/                      React + TypeScript: меню, игровая сцена, три темы
  public/assets/images/     пять используемых оригинальных иллюстраций
```

Повторное извлечение из соседней оригинальной сборки:

```powershell
python tools/extract_sources.py
```

Или из другого каталога `game`:

```powershell
python tools/extract_sources.py "C:\путь\к\сборке\game"
```

Команда запускается из `orsk-web`, обновляет архивные копии и автоматически создаваемые выгрузки. Редактировать сюжет для будущей игры следует в отдельном рабочем формате, описанном в архитектуре. Оригинальная сборка при извлечении не изменяется.

Архив `source/` не входит в сборку сайта. Из него автоматически берутся только пять нужных игровых иллюстраций, без GUI Ren’Py. Git-репозиторий автоматически не создавался.
